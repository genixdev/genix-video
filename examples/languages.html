One button.
Your languages.

This page never creates or modifies cookies. The selector changes lang. Missing translations use playlabel, then the internal English default Play.

Explicit language

Regional attributes take precedence, followed by the base language and default text. Translation values intentionally retain their own language.

<genix-video id="translated" lang="en-US" size="fullwidth" max-height="55dvh" background="poster"
  provider="native" src="assets/sample.mp4" poster="assets/sample-poster.jpg" fullscreen="true"
  playlabel="Watch video" playlabel-en="Play" playlabel-en-us="Watch now"
  playlabel-es="Reproducir" playlabel-fr="Lire" playlabel-it="Riproduci" playlabel-de="Abspielen"
  loadinglabel-fr="Chargement…" retrylabel-fr="Réessayer" errorlabel-fr="Lecture impossible."
  fullscreenlabel-fr="Plein écran" exitfullscreenlabel-fr="Quitter le plein écran"></genix-video>

Read an existing site cookie

Only SETLANG is read here, if available to JavaScript on this domain/path. A missing cookie or translation falls back to Watch video. No cookie is written.

<genix-video id="cookie-video" lang-cookie="SETLANG" size="fullwidth" max-height="300" provider="native" src="assets/sample.mp4" poster="assets/sample-poster.jpg" playlabel="Watch video" playlabel-en="Play" playlabel-es="Reproducir" playlabel-fr="Lire"></genix-video>
// After your website changes its own language cookie:
document.getElementById('cookie-video').refreshLanguage();

No configured label

Without a translated or base playlabel, the generated button says Play.
