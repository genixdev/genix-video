1. Install two files

Copy src/gennix-video.js and src/gennix-video.css to your web server. Adjust these paths to your installation. No dependencies, npm install or build required. Serve through HTTP(S).

<link rel="stylesheet" href="/gennix-video/src/gennix-video.css">
<script src="/gennix-video/src/gennix-video.js" defer></script>

2. Add a video

<gennix-video size="fullwidth" aspect-ratio="16/9"
  max-height="80dvh" background="poster"
  provider="youtube" src="HuACikeyg0c">
</gennix-video>

The × closes the video and restores its poster. It overlays the corner without reducing player height. Use close-button="false" to hide it.

Fullwidth

Fills the parent width. Height follows 16/9. Change aspect-ratio to reserve another shape.

<gennix-video id="inline-video" size="fullwidth" aspect-ratio="16/9" provider="youtube" src="HuACikeyg0c" max-height="80dvh" background="poster" aria-label="YouTube inline"></gennix-video>

Custom dimensions

900 × 500 pixels, reduced in width to fit a smaller parent. Use height="auto" for a ratio-derived height.

<gennix-video size="custom" width="900" height="500" provider="native" src="assets/sample.mp4" poster="assets/sample-poster.jpg" background="poster"></gennix-video>

Vertical video

Native metadata keeps all four edges visible, without changing the reserved height.

<gennix-video size="custom" width="900" height="400" provider="native" src="assets/portrait.mp4" poster="assets/portrait-poster.jpg" background="poster"></gennix-video>

Square video

Declare the known ratio to reserve the right space before loading.

<gennix-video size="custom" width="400" height="auto" aspect-ratio="1/1" provider="native" src="assets/square.mp4" poster="assets/square-poster.jpg"></gennix-video>

Native cover

Cover crops the picture to fill the box. YouTube always stays contained.

<gennix-video size="custom" width="900" height="300" fit="cover" provider="native" src="assets/portrait.mp4" poster="assets/portrait-poster.jpg"></gennix-video>

Configuration reference

Boolean values: empty or true enables; false disables. Missing or unknown values use the default. Playback attributes are read when preparing a new player; reset before changing a loaded player. Size attributes update immediately.

Language fallback

Regional translation → base language → unsuffixed attribute → built-in English text. A configured cookie is read only; never created or modified. Missing playlabel falls back to Play. See the language demo for full examples.

Methods and events

play() and requestFullscreen() return promises. pause(), reset() and refreshLanguage() are synchronous. Events: gennix:statechange, gennix:ready, gennix:play, gennix:pause, gennix:ended and gennix:error. Read the README for contracts and optional CSS customization.
